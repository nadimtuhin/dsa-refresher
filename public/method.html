The 6 step method (say it out loud)

Interviewers grade how you think as much as the code. Narrate everything.

1. Repeat"So I get X and return Y." Confirms you understood.
2. ClarifyEmpty input? Duplicates? Negatives? Sorted? Size of n? Can I modify the input?
3. ExampleWalk one small example by hand, plus one edge case.
4. Brute forceSay it with its Big O. Don't code it unless asked.
5. Improve, then codeName the pattern ("hash map", "two pointers"). Code it clean, with good names.
6. TestRun your example through the code line by line. Then edge cases. Then state time and space.

When stuck

  • "Let me try a smaller example." Then do it.
  • "I'll start with the brute force so we have something correct, then optimise."
  • Ask: "Am I on the right track?" Interviewers usually nudge.
